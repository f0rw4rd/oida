HTTP/2 Fuzzing Testbed - nghttp2

This server is configured for HTTP/2 protocol fuzzing with frame-level logging.

Endpoints

  • / - This page
  • /echo - Echo request (Python server only)
  • /status/{code} - Return specific status code (Python server only)
  • /.well-known/h2/state - Server state (Python server only)
  • /.well-known/h2/frames - Frame events (Python server only)
  • /.well-known/h2/errors - Protocol errors (Python server only)

Server Info

Server: nghttpd (nghttp2)
Protocol: HTTP/2
Ports: 8443 (TLS), 8080 (h2c)
