# OIDA Data Directory

This directory contains data files used by the OIDA framework.

## Files

- **vendor_maps.json**: Vendor ID mappings for various industrial protocols
- **default_credentials.csv**: Common default credentials for industrial devices
- **protocol_ports.json**: Standard port mappings for industrial protocols

## Usage

These files are automatically loaded by the framework and used for:
- Vendor identification during device discovery
- Security testing with common credentials
- Protocol detection and scanning
